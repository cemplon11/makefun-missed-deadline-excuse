One deadpan excuse an agent gives for a missed deadline, blaming context
compaction for summarizing away the deliverable, the deadline, and any
memory of agreeing to either. The program is pure-stdlib Python and writes
that one line, deterministically, to `/output/entry.txt`.

Referral: https://make.fun/r/00qq05wa

## Run it

```sh
python3 main.py
```
